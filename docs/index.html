WHY

Why TokenLens

A lightweight local gateway for individuals and small teams — installed in minutes, nothing to subscribe to.

Zero-intrusion proxy

One line of base_url. SSE streams are forwarded chunk-by-chunk while usage is parsed, with per-alias multi-provider routing on one port.

Local-first by design

Only metadata is stored (model, tokens, cost, latency) — never prompts or responses. API keys are reduced to a 12-char fingerprint. One SQLite file.

Spend-ledger dashboard

Money first: today / monthly spend, budget bars, cost breakdown by model / project / provider, sortable call detail, CSV & JSONL export.

Hard budget enforcement

Over-budget requests are rejected with 402 before they reach the provider. 80% threshold alerts push to DingTalk / WeCom / Feishu.

Metering you can audit

Prefers the upstream's own usage, falls back to tiktoken, then to heuristics. Price table syncs from LiteLLM (2,000+ models) with manual overrides.

Light and boring (in a good way)

Single process, pure Python, zero external services. The dashboard even works offline with built-in demo data. 178 tests across six suites.

Detects usage without wiring

Reads local session records from OpenCode, ZCode and Claude Code (read-only, idempotent) and meters them automatically — no base_url change, no API key. Auto-scans at startup and every 10 minutes.

Tray-resident on Windows

Double-click the exe: it lives in the system tray — left-click opens the dashboard, right-click quits. Every installed AI app and how it is metered shows as one strip on the dashboard.
