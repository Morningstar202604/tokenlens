TokenLens はローカルで動く透過プロキシです。base_url を1行変えるだけで、すべての呼び出しのトークン数・コスト・レイテンシを記録し、支出台帳ダッシュボードと予算ハードブロックを提供します。業務コードにも API キーにも触れません。

WHY

TokenLens が選ばれる理由

個人と小規模チームのための軽量ローカルゲートウェイ — 数分で導入でき、サブスクリプションは不要です。

ゼロ侵入プロキシ

base_url を1行変えるだけ。SSE をチャンク単位で転送しながら usage を解析し、1ポートで複数プロバイダをエイリアスルーティング。

設計からローカルファースト

保存するのはメタデータのみ。プロンプトとレスポンスは保存せず、API キーは12文字のフィンガープリントだけ。SQLite1ファイル。

支出台帳ダッシュボード

お金を主役に：今日/今月の支出、予算バー、モデル/プロジェクト/プロバイダ別の内訳、ソート可能な明細、CSV/JSONL 出力。

予算ハードブロック

予算超過のリクエストはプロバイダに届く前に 402 で拒否。80%しきい値のアラートは DingTalk / WeCom / Feishu へ。

検証可能な計測

上流の usage を最優先し、tiktoken、ヒューリスティックへ段階フォールバック。価格テーブルは LiteLLM（2,000+ モデル）から同期、手動上書き可。

軽量で堅実

単一プロセス、純 Python、外部サービス不要。内蔵デモデータでオフラインでも動作。6スイート178テスト。

接続なしで使用量を検出

OpenCode・ZCode・Claude Code・Codex CLI・Gemini CLI・Qwen Code・iFlow・aider・Cline・Roo Code のローカルセッション記録を読み取り専用で走査（冪等）し自動計測 — base_url の変更も API キーも不要。コストはアプリ記録値または定価見積り（無料/単価不明はその旨表示）。起動時と 10 分ごとに自動スキャン。

Windows トレイ常駐

exe をダブルクリックするとトレイに格納 — 左クリックでダッシュボード、右クリックで終了。各アプリの計測方法はダッシュボードの一枚のストリップに表示。

HOW

1つのポートがパスエイリアスで全プロバイダへルーティング。X-TokenLens-Project で部門タグを付けられます。Authorization ヘッダはそのまま転送され、保存されません。
